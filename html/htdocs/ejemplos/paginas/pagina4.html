El Valor Absoluto

La distancia de un número al cero

Definición | Ejemplos | Propiedades | Ecuaciones | Inecuaciones | Usos

¿Qué es el valor absoluto?

El valor absoluto de un número es la distancia que hay entre ese número y el cero en la recta numérica. Como una distancia nunca es negativa, el valor absoluto siempre es positivo o cero.

Se escribe con dos barras verticales: |x|, y se lee "valor absoluto de x".

Definición formal

|x| = x    si x ≥ 0
|x| = −x    si x < 0

Es decir: si el número es positivo o cero, se queda igual; si es negativo, se le cambia el signo.

Ejemplos

Número Valor absoluto Explicación
5|5| = 5Está a 5 unidades del cero
−5|−5| = 5También está a 5 unidades del cero
0|0| = 0El cero está a distancia 0 de sí mismo
−3,7|−3,7| = 3,7Funciona igual con decimales
−2/3|−2/3| = 2/3Funciona igual con fracciones
8 − 12|8 − 12| = |−4| = 4Primero se resuelve lo de adentro

Propiedades

  1. No negatividad: |a| ≥ 0 para cualquier número a.
  2. Solo el cero vale cero: |a| = 0 únicamente si a = 0.
  3. Simetría: |−a| = |a|.
  4. Producto: |a · b| = |a| · |b|.
  5. Cociente: |a / b| = |a| / |b|  (con b ≠ 0).
  6. Desigualdad triangular: |a + b| ≤ |a| + |b|.
  7. Distancia entre dos números: la distancia entre a y b es |a − b|.

Cuidado: |a + b| no siempre es igual a |a| + |b|.
Ejemplo: |3 + (−5)| = |−2| = 2, pero |3| + |−5| = 3 + 5 = 8.

Ecuaciones con valor absoluto

Si |x| = a (con a positivo), entonces hay dos soluciones: x = a o x = −a.

Ejemplo 1

|x| = 7  →  x = 7  o  x = −7

Ejemplo 2

|x − 3| = 5
x − 3 = 5  →  x = 8
x − 3 = −5  →  x = −2
Soluciones: x = 8 y x = −2

Ejemplo 3 (sin solución)

|x| = −4 no tiene solución, porque un valor absoluto nunca puede ser negativo.

Inecuaciones con valor absoluto

  • |x| < a significa −a < x < a (los números cerca del cero).
  • |x| > a significa x < −a o x > a (los números lejos del cero).

Ejemplo

|x − 2| < 3
−3 < x − 2 < 3
−1 < x < 5
Solución: todos los números entre −1 y 5.

¿Para qué se usa?

  • Distancias: la distancia entre dos puntos siempre es positiva.
  • Temperaturas: la diferencia entre −3 °C y 5 °C es |5 − (−3)| = 8 °C.
  • Errores de medición: el error es |valor medido − valor real|.
  • Programación: casi todos los lenguajes tienen una función abs().
En resumen: el valor absoluto "quita el signo" y nos dice qué tan lejos está un número del cero.
